# Security Policy

If you discover a security vulnerability in Imanapharma, please report it privately.

## Reporting

1. Open a GitHub issue and tag it as a security issue, or
2. Contact the repository owner directly if you have an alternate secure channel.

Do not include exploit details or sensitive data in a public issue.

## Response

We will review security reports promptly and respond with remediation steps or patches.

## Supported versions

We currently support the latest `main` branch as the active codebase.
